# 🎙️ Micrófono n8n Trigger

Aplicación web minimalista que funciona como un botón de micrófono para activar triggers en n8n mediante webhooks.

## Características

- 🎤 Interfaz moderna con micrófono animado
- 📱 Diseño responsive (móvil/tablet/desktop)
- ⚡ Activación mediante webhook de n8n
- 🎨 Feedback visual con ondas y cambios de color
- 💾 Configuración persistente de la URL del webhook
- 🔄 Manejo de errores y estados de conexión

## Requisitos previos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Instancia de n8n (local o cloud)
- Webhook configurado en n8n
